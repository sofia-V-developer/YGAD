### ДОКУМЕНТАЦИЯ ПРОЕКТА YGAD  — Умный журнал успеваемости

*1.Введение*
Назначение приложения
YGAD — мобильное приложение для учёта успеваемости студентов группы. Приложение позволяет:
- Регистрироваться студентам и старостам
- Добавлять и просматривать оценки по предметам
- Анализировать средний балл и выявлять предметы в зоне риска
- Добавлять оценки через фото журнала (с помощью OCR)
- Переключать светлую/тёмную тему интерфейса
Целевая аудитория
- Студенты — для отслеживания своей успеваемости
- Старосты — для ведения журнала оценок группы

*3.Установка приложения*
Установка из Android Studio
1. Скачать проект с GitHub
2. Открыть проект в Android Studio
3. Подключить телефон с отладкой по USB
4. Нажать кнопку "Run ▶️'

Установка APK-файла
1. Собрать APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Установить полученный APK-файл на телефон

*4.Руководство пользователя*
Первый вход в приложение
1. Ввести **Имя** и **Фамилию**
2. (Опционально) Нажать **"Выбрать аватарку"** и выбрать фото из галереи
3. (Для старосты) Нажать **"У меня есть код старосты"** → ввести код **524267**
4. Нажать **"Продолжить"**

Главный экран
- Вверху отображается имя пользователя и аватарка
- **Средний балл** и **Долгов** — общая статистика
- **Поиск** — можно искать предметы по названию или преподавателю
- **Список предметов** — все добавленные предметы

Добавление предмета (только для старосты)
1. Нажать **"➕ Добавить предмет"**
2. Ввести **Название предмета** (например, "Высшая математика")
3. (Опционально) Ввести **Преподавателя**
4. Нажать **"Сохранить предмет"**

Удаление предмета (только для старосты)
1. Нажать на нужный предмет
2. В открывшемся экране нажать **"🗑️ Удалить предмет"**
3. Подтвердить удаление

Добавление оценок
Способ 1: Через фото журнала (только для старосты)
1. Нажать на предмет
2. Нажать **"📸 Добавить оценки по фото"**
3. Сфотографировать журнал
4. Открыть фото в любом OCR-приложении (Google Lens, Microsoft Lens)
5. Скопировать распознанный текст
6. Вернуться в приложение и вставить текст
7. Нажать **"Добавить оценки"**
**Формат вставляемого текста:**
```
Булатова 5 5 5 4 5
Воропаева 5 5 5 5 4
Кузнецов 5 5 5 5 4
```

Просмотр оценок
- **Студент** видит только свои оценки
- **Староста** видит оценки всех студентов

Смена темы оформления
- **Долгое нажатие на аватарку** (3-5 секунд)
- Выбрать: Светлая / Тёмная / Системная тема

Выход из аккаунта
- **быстрое нажатие на аватарку** → нажать "Выйти" -  "выход из аккаунта"

*5.Структура базы данных*
Схема Room Database
**Таблица `subjects` (предметы)**
```sql
CREATE TABLE subjects (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    teacher TEXT,
    semester INTEGER
);
```

**Таблица `students` (студенты)**
```sql
CREATE TABLE students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    lastName TEXT NOT NULL,
    firstName TEXT NOT NULL,
    studentGroup TEXT
);
```

**Таблица `grades` (оценки)**
```sql
CREATE TABLE grades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    subjectId INTEGER NOT NULL,
    studentId INTEGER NOT NULL,
    value INTEGER NOT NULL,
    type TEXT,
    date INTEGER NOT NULL,
    source TEXT,
    FOREIGN KEY(subjectId) REFERENCES subjects(id) ON DELETE CASCADE,
    FOREIGN KEY(studentId) REFERENCES students(id) ON DELETE CASCADE
);
```

*3.База данных*
Версионирование
- Текущая версия БД: **3**
- При изменении схемы **обязательно** увеличивай версию
```java
@Database(entities = {Subject.class, Grade.class, Student.class}, version = 4)
```
Миграции
При изменении структуры БД нужно обновить метод в AppDatabase:
```java
public static synchronized AppDatabase getInstance(Context context) {
    if (instance == null) {
        instance = Room.databaseBuilder(
                context.getApplicationContext(),
                AppDatabase.class,
                "ygad_database"
        ).allowMainThreadQueries()
         .fallbackToDestructiveMigration()  // Для разработки
         .build();
    }
    return instance;
}
```
Новые запросы
Добавляй их в соответствующие DAO-классы:
- `SubjectDao` — запросы по предметам
- `GradeDao` — запросы по оценкам
- `StudentDao` — запросы по студентам

*5.Известные проблемы и их решение*
Распознавание русского текста
**Проблема:** Бесплатные OCR-библиотеки плохо распознают русский язык
**Временное решение:** Ручной ввод текста через диалог
**Как улучшить:** Подключить Aspose.OCR (платная) или Google Cloud Vision API
```gradle
// Платный вариант:
implementation 'com.aspose:aspose-ocr:24.9'
```
Камера не открывается
**Проверь:**
1. Разрешения в `AndroidManifest.xml`
2. Разрешения на телефоне (Настройки → Приложения → YGAD → Камера → Разрешить)

База данных не создаётся
**Проверь:**
1. Версия БД совпадает с ожидаемой
2. Все поля в Entity-классах имеют конструкторы
3. `fallbackToDestructiveMigration()` включен
